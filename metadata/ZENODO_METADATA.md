## Description
This reproducibility package supports the study “Explaining Fine-Scale Surface Heat Across a Tropical Volcanic Island Using Spatially Validated GeoAI: Jolo Island, Philippines”. It contains frozen analysis-ready model samples, derived LST and seasonal robustness rasters, the physical-island study boundary, analysis code, model-performance outputs, SHAP summaries, residual spatial diagnostics, thermal-regime summaries, seasonal sensitivity results, and publication figures. The package is designed to reproduce and audit the reported downstream statistical and machine-learning analyses. Primary Earth-observation provider archives are not redistributed.
