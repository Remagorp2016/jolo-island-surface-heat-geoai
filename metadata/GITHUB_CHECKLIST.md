# GitHub publication checklist

Recommended repository name:

`jolo-island-surface-heat-geoai`

1. Create a new **public** GitHub repository.
2. Upload the contents of the GitHub-ready ZIP, not the ZIP file itself.
3. Confirm `README.md`, `CITATION.cff`, `LICENSE`, `requirements.txt`, and the `scripts/` folder render correctly.
4. Create an initial GitHub release tagged `v1.0.0`.
5. In the repository description, use:
   `Spatially validated explainable GeoAI for Jolo Island land surface temperature, Philippines.`
6. Add repository topics such as:
   `landsat`, `land-surface-temperature`, `geoai`, `shap`, `spatial-cross-validation`, `remote-sensing`, `philippines`.
7. After the Zenodo record is published, add the Zenodo DOI badge/link to `README.md`.

The GitHub package intentionally omits the largest GeoTIFF intermediates. Those belong in the full Zenodo archival package.
