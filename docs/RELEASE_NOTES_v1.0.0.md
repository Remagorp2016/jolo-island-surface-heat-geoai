# Release v1.0.0

Initial public reproducibility release for:

**Explaining Fine-Scale Surface Heat Across a Tropical Volcanic Island Using Spatially Validated GeoAI: Jolo Island, Philippines**

Included:
- frozen main modeling sample (8,838 observations);
- frozen seasonal robustness sample;
- physical-island and municipality boundary derivatives;
- final statistical and machine-learning reproduction script;
- representative Earth Engine preprocessing scripts;
- model-performance, SHAP, residual, thermal-regime, and sensitivity outputs;
- publication figures;
- metadata, declarations, citation, and environment files.

Large intermediate GeoTIFFs are included only in the full Zenodo archival bundle, not in the GitHub-light bundle.
