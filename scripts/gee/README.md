# Google Earth Engine scripts

These scripts document the final upstream Earth Engine design used for the primary MAM LST response and the seasonal robustness raster.

The scripts assume the physical-island boundary has been uploaded to the user's Earth Engine assets as:

`projects/sulu-flood-research/assets/Jolo_Island_AOI`

Replace that asset path if reproducing under another Earth Engine account.

The repository's frozen analysis-ready CSVs are the authoritative inputs for reproducing the reported downstream statistical and ML results.
